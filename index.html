Web-based Presentation Design

မိတ်ဆက် (Introduction)

JavaScript ရေးတဲ့အခါ အချို့သော လုပ်ငန်းစဉ်တွေကို အချိန်တစ်ခု သတ်မှတ်ပြီး အလုပ်လုပ်ခိုင်းချင်တဲ့ အခါမျိုးတွေ ရှိပါတယ်။

ဥပမာ - နာရီပြတာ၊ ပုံတွေ အလိုအလျောက်ပြောင်းတာ စသည်တို့ ဖြစ်ပါတယ်။

JavaScript သည် Single-threaded ဖြစ်သည်

ဆိုလိုသည်မှာ JavaScript သည် တစ်ကြိမ်လျှင် အလုပ် (Task) တစ်ခုကိုသာ လုပ်ဆောင်နိုင်ပါသည်။

ဒါဆိုရင် အချိန်စောင့်ရမယ့် အလုပ်တွေကို ဘယ်လိုလုပ်မလဲ?

Web APIs များ

Browser တွေမှာ JavaScript အပြင် အခြားသော ကူညီပေးမယ့် Web APIs တွေ ပါဝင်ပါတယ်။

အချိန်နဲ့ သက်ဆိုင်တဲ့ လုပ်ဆောင်ချက် (Timers) တွေကို Web APIs က တာဝန်ယူပေးပါတယ်။

အဓိက Function (၂) ခု

  • setTimeout() : အချိန်တစ်ခု စောင့်ပြီးမှ တစ်ကြိမ်သာ အလုပ်လုပ်သည်။
  • setInterval() : သတ်မှတ်ထားသော အချိန်တိုင်းမှာ ထပ်တလဲလဲ အလုပ်လုပ်သည်။

ဒီနေ့ ကျွန်တော်တို့ setInterval ကို အဓိက လေ့လာသွားပါမယ်။

setInterval ဆိုတာ ဘာလဲ?

ကုဒ် (Code) အပိုင်းအစတစ်ခုကို မိမိသတ်မှတ်ထားသော အချိန်အပိုင်းအခြား (Time Interval) တစ်ခုတိုင်းမှာ အဆုံးမရှိ ထပ်တလဲလဲ အလုပ်လုပ်ခိုင်းစေသော Function ဖြစ်ပါတယ်။

setInterval ၏ Syntax


setInterval(function, delay, arg1, arg2, ...)

Parameters သုံးခု ပါဝင်ပါတယ်။ တစ်ခုချင်းစီကို ကြည့်ရအောင်။

Parameter (၁): function

ထပ်တလဲလဲ အလုပ်လုပ်စေချင်တဲ့ Callback Function ဖြစ်ပါတယ်။


setInterval(() => {
    // လုပ်ဆောင်မည့် အရာများ
}, 1000);

Parameter (၂): delay

ဘယ်လောက်ကြာတိုင်း တစ်ခါ အလုပ်လုပ်မလဲ ဆိုတဲ့ အချိန် (Milliseconds) ဖြစ်ပါတယ်။

  • 1 Second = 1000 Milliseconds
  • 2 Seconds = 2000 Milliseconds

Parameter (၃): arguments

ဒါကတော့ Option (မထည့်လည်း ရပါတယ်)။ Function ဆီကို Data တွေ လှမ်းပို့ချင်ရင် သုံးပါတယ်။


function greet(name) {
    console.log("Hello " + name);
}
setInterval(greet, 1000, "Aung Aung");

ဥပမာ (၁): ရိုးရှင်းသော စာထုတ်ခြင်း


setInterval(function() {
    console.log("မြန်မာစာ လေ့လာကြစို့");
}, 2000);

အထက်ပါ Code သည် ၂ စက္ကန့်ပြည့်တိုင်း စာကြောင်းကို Console ထဲတွင် ပြသနေမည်ဖြစ်သည်။

လုပ်ဆောင်ပုံ အဆင့်ဆင့်

  • 0s: Code စတင်အလုပ်လုပ်
  • 2s: "မြန်မာစာ လေ့လာကြစို့" (ပထမအကြိမ်)
  • 4s: "မြန်မာစာ လေ့လာကြစို့" (ဒုတိယအကြိမ်)
  • 6s: "မြန်မာစာ လေ့လာကြစို့" (တတိယအကြိမ်)
  • ... အဆုံးမရှိ ဆက်သွားနေပါမည်။

ဥပမာ (၂): Counter (ရေတွက်ခြင်း)


let count = 0;

setInterval(() => {
    count++;
    console.log("Current Count: " + count);
}, 1000); // ၁ စက္ကန့်လျှင် တစ်ကြိမ်

Counter ၏ ရလဒ်

Current Count: 1
Current Count: 2
Current Count: 3
...
Current Count: 1000 (And beyond)

ပြဿနာတစ်ခု ပေါ်လာပါပြီ

setInterval သည် အလိုအလျောက် ဘယ်တော့မှ ရပ်တန့်သွားမည် မဟုတ်ပါ။

Browser ကို ပိတ်လိုက်မှ သို့မဟုတ် Tab ကို ပိတ်လိုက်မှသာ ရပ်သွားပါမည်။

ဘာဖြစ်လို့ မကောင်းတာလဲ?

  • Memory Leak: ကွန်ပျူတာရဲ့ Memory တွေကို အလဟဿ စားသုံးနေပါမယ်။
  • Performance: ဖုန်း သို့မဟုတ် ကွန်ပျူတာကို လေးလံသွားစေပါတယ်။
  • Bugs: မလိုအပ်တော့တဲ့ အချိန်မှာ ဆက်အလုပ်လုပ်နေရင် Error တွေ တက်နိုင်ပါတယ်။

အဖြေကတော့...

clearInterval

ရပ်တန့်ဖို့အတွက် ဒီ Function ကို သုံးရပါမယ်။

clearInterval ဆိုတာ ဘာလဲ?

အလုပ်လုပ်နေဆဲဖြစ်သော setInterval ကို ချက်ချင်း ရပ်တန့်ပစ်လိုက်သော Function ဖြစ်ပါသည်။

clearInterval ၏ Syntax


clearInterval(intervalID)

ဒီနေရာမှာ မေးစရာရှိလာတာက... intervalID ဆိုတာ ဘာလဲ?

Interval ID ဆိုတာ ဘာလဲ?

setInterval ကို ခေါ်လိုက်တဲ့အခါ သူ့ကို မှတ်သားထားနိုင်ဖို့ သီးသန့် နံပါတ် (Unique ID) တစ်ခုကို ပြန်ပေး (Return) ပါတယ်။

ထို ID သည် ပုံမှန်အားဖြင့် ကိန်းပြည့် (Integer Number) ဖြစ်ပါတယ်။

ID ကို ဘယ်လို သိမ်းမလဲ?

Variable တစ်ခု တည်ဆောက်ပြီး သိမ်းထားရပါမယ်။


const myTimerID = setInterval(() => {
    console.log("Working...");
}, 1000);

console.log(myTimerID); // e.g., 1 or 2

ID ကို အသုံးပြု၍ ရပ်တန့်ခြင်း

ထို သိမ်းထားသော myTimerID ကို clearInterval ထဲသို့ ထည့်ပေးလိုက်ရုံပါပဲ။


clearInterval(myTimerID);

အပြည့်အစုံ ဥပမာ (၃)

၅ စက္ကန့်ပြည့်ရင် Counter ကို ရပ်တန့်ကြစို့။


let count = 0;
let timerID; 

timerID = setInterval(() => {
    count++;
    console.log(count);
    if(count === 5) {
        clearInterval(timerID); // ၅ ပြည့်ရင် ရပ်မည်
    }
}, 1000);

ဥပမာ (၃) ကို ခွဲခြမ်းစိတ်ဖြာခြင်း

  1. timerID ထဲကို Interval အလုပ်လုပ်တဲ့ ID ထည့်သိမ်းတယ်။
  2. ၁ စက္ကန့်ပြည့်တိုင်း count ကို ၁ တိုးတယ်။
  3. count === 5 ဖြစ်သွားတဲ့အခါ...
  4. clearInterval(timerID) ကို ခေါ်လိုက်တဲ့အတွက် ချက်ချင်း ရပ်သွားပါတယ်။

Button နှိပ်၍ ရပ်တန့်ခြင်း


let id = setInterval(() => {
    console.log("Running...");
}, 1000);

document.getElementById("stopBtn")
        .addEventListener("click", () => {
            clearInterval(id);
            console.log("Stopped!");
});

လက်တွေ့ အသုံးချမှုများ

Real-World Use Cases

(၁) ဒစ်ဂျစ်တယ် နာရီ (Digital Clock)

အချိန်ကို စက္ကန့်နဲ့အမျှ ပြောင်းလဲပြသဖို့ setInterval က အကောင်းဆုံးပါ။

Digital Clock Code


setInterval(() => {
    const date = new Date();
    const timeString = date.toLocaleTimeString();
    
    // UI ပေါ်တွင် အချိန်ကို ပြသခြင်း
    document.getElementById("clock").innerText = timeString;
    
}, 1000); // ၁ စက္ကန့်တိုင်း အသစ်ပြန်ပြမည်

(၂) နောက်ပြန်ရေတွက်ခြင်း (Countdown Timer)

New Year ရောက်ဖို့ ဘယ်လောက်လိုသေးလဲ? Sales Promotion အချိန် ဘယ်လောက်ကျန်သေးလဲ? စသည်တို့အတွက် သုံးနိုင်ပါတယ်။

Countdown Code အကြမ်းဖျင်း


let timeLeft = 10;
const countdown = setInterval(() => {
    timeLeft--;
    console.log(timeLeft + " seconds remaining");
    
    if (timeLeft <= 0) {
        clearInterval(countdown);
        console.log("Time's up!");
    }
}, 1000);

(၃) ပုံများ အလိုအလျောက်ပြောင်းခြင်း (Image Carousel/Slider)

Website တွေရဲ့ မျက်နှာဖုံးမှာ ပုံတွေ ၃ စက္ကန့် တစ်ခါ အလိုလို ပြောင်းသွားတာ တွေ့ဖူးမှာပါ။ ဒါလည်း setInterval ကို သုံးထားတာပါ။

Slider Code အကြမ်းဖျင်း


let currentImageIndex = 0;
const images = ['img1.jpg', 'img2.jpg', 'img3.jpg'];

setInterval(() => {
    currentImageIndex++;
    if(currentImageIndex >= images.length) {
        currentImageIndex = 0; // အစက ပြန်စမည်
    }
    changeImage(images[currentImageIndex]);
}, 3000); // ၃ စက္ကန့် တစ်ကြိမ် ပြောင်းမည်

(၄) Data အသစ် လှမ်းယူခြင်း (API Polling)

ဥပမာ - Facebook Message အသစ်ဝင်မဝင် ၅ စက္ကန့် တစ်ခါ Server ကို လှမ်းမေးတဲ့အခါမျိုးမှာ အသုံးပြုပါတယ်။

API Polling Code


const pollInterval = setInterval(async () => {
    try {
        let response = await fetch('/api/messages');
        let data = await response.json();
        updateUI(data);
    } catch(err) {
        console.error(err);
        clearInterval(pollInterval); // Error တက်ပါက ရပ်မည်
    }
}, 5000);

အဆင့်မြင့် သိမှတ်ဖွယ်ရာများ

Advanced Topics & Best Practices

သတိပြုရမည့် အချက်များ (Pitfalls)

setInterval ကို သုံးတဲ့အခါ အလွယ်တကူ မှားတတ်တဲ့ အချက် (၄) ချက် ရှိပါတယ်။

(၁) Memory Leaks

Single Page Applications (ဥပမာ React, Vue) တွေမှာ Page ပြောင်းသွားပေမယ့် Interval တွေက နောက်ကွယ်မှာ ဆက်အလုပ်လုပ်နေတတ်ပါတယ်။

ရှင်းလင်းရန် အရေးကြီးသည်

Component မဖျက်ခင် သို့မဟုတ် Page မပြောင်းခင် clearInterval ကို မဖြစ်မနေ ခေါ်ပေးရပါမယ် (Cleanup function)။

(၂) this Keyword ပြဿနာ

Object တွေထဲမှာ setInterval သုံးတဲ့အခါ this ရဲ့ တန်ဖိုးက Window Object ကို ရည်ညွှန်းသွားတတ်ပါတယ်။

Arrow Function အသုံးပြုခြင်း

ဒီပြဿနာကို ဖြေရှင်းဖို့ ES6 ရဲ့ Arrow Function (=>) ကို အသုံးပြုသင့်ပါတယ်။ Arrow Function က this ကို မှန်ကန်စွာ ထိန်းသိမ်းပေးပါတယ်။

(၃) အချိန်တိကျမှု မရှိခြင်း (Inaccuracy)

JavaScript setInterval(..., 1000) လို့ ရေးတိုင်း တိတိကျကျ ၁ စက္ကန့်တိုင်း အလုပ်လုပ်မယ်လို့ အာမခံချက် မရှိပါဘူး။

ဘာကြောင့်လဲ? (Event Loop)

JavaScript ဟာ Thread တစ်ခုတည်းရှိလို့၊ တခြားလေးလံတဲ့ အလုပ်တွေ (Heavy Tasks) ရှိနေရင် Timer က အချိန်စေ့သွားတောင် ချက်ချင်း အလုပ်မလုပ်နိုင်ဘဲ စောင့်နေရပါတယ်။

Call Stack ပိတ်ဆို့ခြင်း

Expected: 1s -> 2s -> 3s

Reality: 1s -> 2.2s -> 3.5s (တခြားအလုပ်တွေကြောင့် နောက်ကျခြင်း)

(၄) အလုပ်တွေ ထပ်သွားခြင်း (Overlapping)

သင်ခိုင်းလိုက်တဲ့ Function လုပ်ဆောင်ဖို့ ကြာချိန်က Delay အချိန်ထက် ပိုကြာနေရင်၊ ပထမတစ်ခု မပြီးခင် နောက်တစ်ခု ထပ်ရောက်လာပြီး ပြဿနာတက်နိုင်ပါတယ်။

ပိုကောင်းတဲ့ အခြားရွေးချယ်စရာ (Alternative)

Recursive setTimeout

Recursive setTimeout ဆိုတာ ဘာလဲ?


function repeatFunc() {
    // အလုပ်လုပ်ရန်
    console.log("Working...");

    // ပြီးမှ နောက်တစ်ကြိမ် ပြန်ခေါ်ရန်
    setTimeout(repeatFunc, 1000);
}
setTimeout(repeatFunc, 1000);

ဘာကြောင့် ပိုကောင်းတာလဲ?

ပထမ အလုပ် လုံးဝ ပြီးဆုံးသွားမှသာ နောက်တစ်ကြိမ်အတွက် အချိန်စမှတ်တဲ့အတွက် အလုပ်တွေ ထပ်သွားခြင်း (Overlapping) လုံးဝ မဖြစ်နိုင်တော့ပါဘူး။

Animation များအတွက် အထူး

Web ပေါ်မှာ ချောမွေ့တဲ့ Animation တွေ (ဥပမာ ဂိမ်းတွေ) ရေးမယ်ဆိုရင် setInterval ထက် requestAnimationFrame ကို အသုံးပြုတာက Performance အကောင်းဆုံး ဖြစ်ပါတယ်။

အကျဉ်းချုပ် (Summary)

  • setInterval - သတ်မှတ်ထားသော အချိန်တိုင်း ထပ်တလဲလဲ အလုပ်လုပ်သည်။
  • clearInterval - အလုပ်လုပ်နေသည်ကို ရပ်တန့်စေသည်။
  • အမြဲတမ်း id သိမ်းထားပြီး မလိုအပ်တော့ရင် Clear လုပ်ဖို့ မမေ့ပါနဲ့။
  • တိကျမှု အလွန်လိုလျှင် သို့မဟုတ် အလုပ်တွေ ထပ်မှာစိုးလျှင် Recursive setTimeout ကို စဉ်းစားပါ။
